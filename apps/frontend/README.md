# Frontend

Web dashboard (React + TypeScript, Vite, TanStack Router + Query, Tailwind) for Capybara Cloud.
Commands below run from the repository root with `nx`; see the root `README.md` for installation.

## Development

```
nx dev frontend        # pnpm dev: http://localhost:5173, proxies /api to the backend
nx test frontend       # pnpm test: vitest
nx typecheck frontend  # pnpm typecheck: tsc -b
nx build frontend      # pnpm build: static output in apps/frontend/dist/
```

Run the backend alongside it with `nx run-many -t dev -p backend frontend`.

## API Proxy

The backend authenticates with a `SameSite=Strict`, `HttpOnly` `sid` cookie, so the app must reach
the API on its own origin. In dev, Vite proxies `/api` to `http://localhost:8888`; in production,
serve `dist/` and `/api` behind the same host.

## Environment Variables

Read from the shell by `vite.config.ts`:

```
# Backend the dev server proxies /api to (default http://localhost:8888)
API_URL=
```

Loaded from `apps/frontend/.env` (not read by the app yet):

```
VITE_SUPABASE_URL=
VITE_SUPABASE_PUBLISHABLE_KEY=
```

## Source Structure

`src` is organized by domain, one folder per backend domain (`organizations`, `projects`, ...).
See `.claude/rules/frontend-structure.md` for the full rules.

```
src/
  api/              # request/ApiError core: URLs, cookies, response envelope (createApi())
  components/       # shared, domain-agnostic components
  lib/              # shared helpers
  <domain>/
    layout/         # shell shared by the domain's sub-routes
    data/           # hooks: the only way UI reads or modifies the domain's data
    components/<name>/<name>.tsx
  routes/           # TanStack Router file routes; _authed/ requires a session
  routeTree.gen.ts  # generated by the router plugin, do not edit
```

`organizations` and `projects` data hooks currently return fixtures (`data/fixtures.ts`) shaped
like the backend responses, until they are wired to the API.
